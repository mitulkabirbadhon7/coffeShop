# Chocobliss Coffee Shop — Project Overview

## Purpose
Chocobliss is a premium editorial coffee-shop web application built as a production-oriented portfolio project. It combines an immersive public website with Supabase authentication, PostgreSQL/RLS, customer accounts, order history, and a secure admin dashboard.

## Core Stack
- Next.js App Router
- TypeScript
- Supabase Auth
- Supabase PostgreSQL
- Supabase Storage
- Zod
- Vercel
- GitHub Actions
- Playwright for E2E
- Vitest/Jest-compatible unit/integration testing as selected by the implementation

## Product Areas
1. Public marketing site
2. Authentication
3. User account
4. Orders
5. Admin dashboard
6. Content management
